# Anna website

Public product introduction, macOS download, and optional coffee support.
The site uses static HTML, CSS, JavaScript, and an original generated watercolor illustration.
The payment images come from the product owner. Their QR contents remain unchanged.

## Preview

Run `python3 -m http.server 4399 --directory website/public` from the repository root.

## Deploy

With authenticated Wrangler, run `pnpm dlx wrangler deploy --config website/wrangler.jsonc`.
The public site is `https://anna.mayuanyuan.top`.
The source repository remains private. Public installers use `YuanyuanMa03/anna-downloads` releases.

## Product boundaries

The page describes the current desktop preview. It does not claim microphone input or long-term memory.
The download area states the Apple signing status and the need for a personal model provider.
The owner confirmed public distribution of the bundled third-party assets on 2026-10-16.
Original third-party licenses still apply.
