# Anna 服务工作台：开始试用

此版本提供总览、服务接入、设备密钥、用量额度、部署连接和静音试用区。界面与 Anna 桌面共用，不再使用 New API 原管理页面作为主要入口。后端仍是已有 New API 实例；未重新创建账本或更改旧设备 Key。

## 打开工作台

需要 Node.js 24+；在已拉取本分支的仓库目录执行：

```sh
node apps/gateway/cli.mjs init
node apps/gateway/cli.mjs start
```

已有配置时不要重复 init。start 是前台进程，不注册登录启动，不启动任何模型。在另一终端执行：

```sh
node apps/gateway/cli.mjs open
```

也可直接打开 `http://127.0.0.1:17865/`，用已有 New API 账号登录。Anna 桌面中的入口是“更多 → 服务工作台”。关闭页面不停止独立服务；停止用 `node apps/gateway/cli.mjs stop`。

工作台默认 consolePort 为 17865，始终仅监听回环；模型数据入口默认 17864。不要把控制端口或工作台代理到公网。配置还支持 publicURL（发给设备的外部地址，默认空）和 allowLocalLLM（是否允许在界面接入本机 LLM，默认 false）。数据目录及三平台原生命令见 [部署说明](gateway-deployment.md)。

## 先完成一件小事

1. 在“服务接入”查看现有路线。接入模型时填写服务商 API 根地址、模型 ID 和 Key；当前支持 OpenAI 兼容协议，新模型可能还需在后端配置计价。第三方地址不自动标为官方。启用只改变路由状态，不是推理验证成功。
2. 创建设备 Key：选择允许模型、初始内部点数和有效期。Key 只在创建结果中展示，随后可带着它直接去试用；旧设备 Key 不会变化。
3. 选择文字、语音合成或语音识别，主动发送一次短请求。会产生少量调用，文本和音频发到选定服务；不开放文件修改或命令执行。生成语音默认静音，可下载，再上传给语音识别。页面不申请摄像头/麦克风。
4. 在“用量额度”查看后端实际记录。语音估算 token 不当作真实 LLM token；未报告的值显示未知。
5. 可设置设备的新可用余额或撤销 Key。余额操作保留原模型范围、IP、有效期等字段，是余额替换，不是原子增量充值，也不表示收到付款；建议设备空闲时调整。撤销后新请求拒绝，已开始的底层推理可能仍在结束。

填写失败保留表单；取消或离开试用区会取消 HTTP 请求，底层模型何时停止取决于模型节点。连接失败时提示显示上次成功数据，不伪造余额或可用状态。

## 让另一台设备使用

“部署连接”提供本机、局域网、可选 Tailscale、已有公共 HTTPS 的指引。可应用监听范围、端口与对外地址；会中断当前数据调用，绑定/保存失败恢复旧入口，并保存上次配置。浏览器不能通过此入口更换后端或公开管理监听。

同一局域网可主动选择 network 与网卡 IP / 0.0.0.0，检查防火墙后使用服务器的局域网地址。Tailscale 是可选项；没有 Tailscale 的客户端也能使用 LAN 或公共 HTTPS。填写 publicURL 不会代建域名、隧道或防火墙规则。HTTP 不加密，不要在不受控网络明文传递 Key。

客户端填 Base URL、自己的设备 Key 和所授权的实际模型 ID。别名不是自动创建的；服务列表显示的模型才是当前配置。网关不会因请求失败而启动本机 LLM。

## 本机账号的快速进入

管理会话在服务端内存中保留最多 8 小时；浏览器使用独立 HttpOnly、SameSite=Strict、限定 /manage 路径的会话 Cookie 恢复刷新后的登录。它不是设备 Key 或上游 access token；这两类 Key 不写入浏览器存储。管理端仅回环 HTTP，不把此 Cookie 方案直接当作公共 HTTPS 管理端部署方案。账号密码只登录对应用户的后端，不用共享管理员代替所有用户；上游 access token 不发送到浏览器。

已有私有凭据文件时，可以明确授权当前 OS 账号快速进入：

```sh
node apps/gateway/cli.mjs open --credentials "/绝对路径/私有凭据.json"
```

文件格式为 admin_username/admin_password。文件不复制到仓库或网关目录；密码、Key 和登录片段不打印。命令通过本机控制引用建立 owner 授权，系统浏览器打开 60 秒、一次性登录链接，兑换后立即清除地址栏片段。

授权期间，同一 OS 账号的 Anna 通过 Main 读取受限控制文件，获取自己的临时工作台链接；Renderer 不读文件/控制 token，子框架不能调用 Main 的接口。退出该工作台账号或重启网关会清除 owner 授权。没有 owner 授权时，Anna 内正常显示登录表单。

独立工作台采用原生 HTML/CSS/JS，让 Git + Node 的部署无前端构建依赖；Vue 桌面通过受限 iframe 共用这份界面。只给 iframe 脚本、表单、下载及主动复制所需权限，不提供 preload、文件、终端、记忆、摄像头或麦克风。

## 验证边界

- 可选真实验收为 `tests/accept-gateway.mjs`，需要本机 Chrome、明确的 ANNA_GATEWAY_REAL=1 与 ANNA_GATEWAY_CREDENTIALS 路径，会创建/撤销临时设备并做两次语音请求。自动测试不运行它，密钥不写入验收报告。
- macOS/Linux 可在命令前设置环境变量；PowerShell 先使用 `$env:ANNA_GATEWAY_REAL="1"` 和 `$env:ANNA_GATEWAY_CREDENTIALS="..."`，再执行 `node tests/accept-gateway.mjs`。
- 当前 Mac 的真实静音流程验证了生成 WAV、上传识别、用量、余额替换与撤销。一次短句“你好，我是安娜”识别为“你好我是安”；直接 ASR 与经网关结果一致。不能据此宣称音质或识别准确率已通过。
- Windows/Linux 原生部署、Intel 目标机、防火墙和跨设备网络仍需实际验收；共享源码和模拟路径不是目标机证据。当前 Mac 不启动本地 LLM，云端模型须由用户配置后再实际验收。
