## 第八批：本地模型持久化与离线准备

- 增加 Main 原生双文件选择，由 Core 校验元数据和大小后导入 Anna 的专用缓存。Renderer 不提交任意文件路径；单次读取最多 1 MB，避免把整个大模型编码进一次 IPC。
