# Gateway 第一批：独立数据入口审阅

2026-11-04；工作分支 `work/anna-senses-v1-20261103`。本批包含此前待提交的网关方案、本地优先规则及手动 CI 触发变更。

## 实现范围

- `apps/gateway/cli.mjs`、`packages/gateway/*.mjs`：零第三方运行依赖的原生 Node 入口，支持 init/start/stop/doctor；根目录命令别名、独立 workspace 描述和 lock importer 同步。
- 数据面仅透传四个白名单接口到明确配置的 New API 后端，保留原设备 Key、模型范围、额度与实际用量的后端权威。不复制上游源码、现有数据库、私有配置、凭据或权重，不实现第二套账本。
- 管理控制仅本机随机端口与临时凭据；对外数据面不转发 `/api/*`。无后台注册、自启、模型下载、模型子进程、全局 agent 配置修改或旧服务切换。
- 新增部署说明；方案明确未实现的工作台、原应用入口、后端安装/迁移及目标平台实测。原独立目录和现有部署保留回退。

## 审阅发现与修复

- **P1 / 上传拒绝与连接释放**：首次超大请求测试超时；提前返回 413 时请求体未读完且连接未明确关闭。拒绝分支改为丢弃剩余输入并关闭连接；chunked 测试显式使用 Transfer-Encoding，避免客户端自动计算 Content-Length 导致没有覆盖流式超限。两类输入均返回 413，且后端无请求。
- **P1 / 凭据转发范围**：只向固定后端、固定路径转发设备 Authorization、Content-Type 与 Accept；禁用重定向跟随，防止凭据被送到重定向目标。Cookie、内部响应头、管理接口均不穿透。日志只有固定元数据。
- **P1 / 生命周期与身份**：独占文件锁、验证本机控制凭据、不凭 PID 杀进程；绑定失败清理自己创建的锁，不能验证的残留锁保留并给出诊断。停止等待锁释放后才报告完成。
- **P2 / 超时与取消**：整次请求 120 秒截止，客户端断开/停止入口取消上游连接；上传未完时同时关闭请求流。超时返回 504，失败/取消写明确的元数据；不自动重试。上游模型是否立即中断仍由上游决定。
- **P2 / 配置与诊断泄漏**：JSON 解析失败不输出原文；doctor 只查询后端状态接口，不发送问候或模型请求，不输出控制凭据。健康检查只表明监听/HTTP 可达，不标记模型验证成功。
- lint 发现 startedAt 在声明前引用，已将定义移动到控制服务创建前；未放宽规则。
