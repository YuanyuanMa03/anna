## 交付与运行边界

- 原生 HTML/CSS/JS 工作台由零依赖 Node 入口提供，Vue 桌面通过受限 iframe 使用同一界面，避免独立网关必须安装前端构建依赖。暖纸色、苔绿、22px 圆角和原创 Anna SVG 应用于全部页面。
- 总览、服务接入、设备 Key、用量/额度、部署连接与静音试用区均连接 New API 实际接口；保留后端的用户身份、现有设备/Key、路由和账本，不创建第二套计费数据库。
- 模型数据面 17864 与仅本机管理面 17865 分开；控制端仍为随机本机端口。设备 Key 不具有管理权限，不向外提供文件、终端、记忆、preload 或麦克风/摄像头能力。
- 提供商 Key 只交给对应用户的后端，前台列表去掉原始 Key、日志正文/内部字段。管理会话为服务端内存，8 小时上限；HttpOnly、SameSite=Strict、/manage Cookie 用于刷新恢复，API Key 不写入浏览器存储。此回环 HTTP 管理模式不作为公网管理端部署方案。
- CLI open 的本机 owner 授权来自显式凭据文件调用，密码不复制到新数据目录或打印；一次性链接 60 秒有效，兑换后清除地址片段。普通网页登录各自校验身份，不使用共享管理员替代所有用户。退出 owner 账号会撤销未来 owner 链接。
- Main 只读取当前 OS 账号的受限控制引用并验证回环链接；新 IPC 校验窗口 ID 和 mainFrame；自动桌面测试在脚本模式直接用隔离夹具，不读真实控制文件。iframe 不获得 preload 权限，复制、下载仅对应用户动作。
- ASR 现用适配源码迁入 `scripts/local-asr`；语音依赖与网关及 LLM 分开，模型权重不入库。只做 Python 语法编译，未启动第二个识别进程；TTS 源码沿用 `scripts/local-speech`。

## 发现、修复与证据

- **P1：额度更新会覆盖连接字段。** New API UpdateToken 是替换 API，原来的部分字段 PUT 不能当作增量充值。新适配器先读取对应用户的设备，再保留模型限制、有效期、IP、group 等字段设置新的可用余额；UI 明确称“设置额度”。真实界面设置 90000 后核对显示，再撤销测试设备；不宣传原子充值、并发结算或人民币支付已实现。
- **P1：管理权限/密钥边界。** 单独本机管理监听、Host/Origin 检查、白名单管理动作、逐用户 JWT 与角色、去除敏感字段；数据试用始终使用设备 Key，不代用管理员 Token。测试覆盖普通用户禁止服务/网络操作、设备 Key 即使附带会话 Cookie 也不能冒用管理身份、退出与单次链接失效。
- **P1：连接应用失败回滚。** 保存前备份配置、独占应用操作；新监听或原子保存失败恢复原地址/原端口，不能把 port=0 的回滚变成另一个随机端口。原生 CLI 测试故意占端口，确认失败后旧健康地址仍可访问、配置未变；不删除非本次创建的 pending 文件。
- **P2：真实操作标签和导航。** 真实页面验收发现 select/textarea 包裹标签被选项或默认文本扩展，按精确名称无法操作；补明确 aria-label。离开/切换试用时取消请求，旧异步结果不写入已销毁页面；加载失败显示上次成功状态而非继续声称新鲜。
- **P2：设备名的 UTF-8 长度。** 后端限制 50 字节，不能把 40 个中文字符视为合格。保留可读前缀并按字节截短，附加 64-bit 随机后缀；测试覆盖 40 个中文字符。前台提示长名截短。只在创建结果暴露本次新 Key，可主动复制含 Key 的客户端配置。
- **P2：验收清理的精确搜索。** 上游 token search 不自动加通配符；验收清理显式使用本次唯一前缀的 % 查询，再严格匹配返回名字。首轮留下的 3 个本轮测试设备已逐一撤销/软删除，原 id=1 的 MacBook Air 设备保留。不会用 broad filter 删除其他设备。
- **P2：跨设备地址和本地节点。** network 模式自动建议网卡地址，仍需用户主动应用并检查防火墙。公共地址/后端要求 HTTPS；本机与明确私网 IP 可 HTTP，但 UI/文档说明明文风险。支持无鉴权私网节点，不自动加载模型。未声称监听成功等于跨设备可达。
- Typecheck 检出新增测试 Server.close 回调与 Promise.resolve 类型不匹配，改用无参数包装回调；没有放宽类型规则。lint/格式只修本轮新增内容。
- 截止时间测试改为后端确实收到请求后触发生产计时回调，不再靠 30ms 的机器速度假设，避免把慢平台当成错误；生产超时仍为 120 秒。
