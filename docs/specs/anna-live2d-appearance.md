# Anna Live2D 外观更新

范围：保留当前正式版的 Host、kernel、消息、记忆、工具、权限、工作区、会话、模型配置和全部功能。仅增加一个可切换的房间外观和专属 Cubism 角色，沿用当前角色的身份、声音设置和既有状态。

素材：基于用户认可的 Anna 原画，圆领长袖针织衫，肩胸完整遮盖。人物和房间分别生成；眼睑和口型为配准表情素材。模型须导出真实 `.moc3` 和 `.model3.json`，由正式版已有 Cubism Core 加载。固定托腮构图支持小幅变形，不承诺大角度转头或自由肢体运动。

验收：Cubism Core 能读取并更新模型；眨眼、口型和头身参数改变渲染结果；输入通过 `window.anna.invoke({type:'send',text})` 交给现有 Host；观察真实模型流式回答和实际工具调用；模型失败不显示预设 AI 回复；设置、权限、历史、工作过程和原有外观可访问；小窗口无关键控件溢出；保存具体截图和验收证据。

本次不增加语音识别或新的 TTS 服务，继续使用正式版已有的朗读功能。口型随既有发言状态驱动，尚非音素级同步。
